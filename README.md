# MicroQuestRPG

A lightweight RPG game for Arduino Micro and similar microcontrollers with simple exploration, combat, inventory management, and progression.

## How to Play

1. Explore the nature and interact with the world
2. Collect useful items and loot
3. Fight enemies in turn-based combat
4. Improve your stats and continue progressing
5. Have fun!

Use the pushbuttons to navigate menus and the OLED display to view the game state.

## Hardware

- Arduino Micro or compatible ATmega32U4 board
- OLED display (SSD1306, 128x64)
- Pushbuttons for input

## OLED and Button Pins

OLED PINS:

VCC: 5V
GND: GND
SCL: Pin A5
SDA: Pin A4

BUTTON PINS:

UP: Pin 4
DOWN: Pin 5
LEFT: Pin 6
RIGHT: Pin 7
## Getting Started

1. Open the project in the Arduino IDE
2. Select the correct board and port
3. Upload the sketch to the board
4. Connect the OLED and buttons to the pins above
5. Power on and start playing
